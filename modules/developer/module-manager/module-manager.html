    The manager scans /modules/, creates missing generated indexes, and refreshes modules.json. Existing hand-written files are preserved.

    Local administration: Run node js/module-manager.js from the COREBIQ project folder. The manager listens only on 127.0.0.1:4177 and should not be exposed publicly.
