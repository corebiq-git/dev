    How synchronisation works

    The manager scans the existing /modules/ directory, creates a missing index.html in each module folder, and refreshes modules.json. Existing hand-written HTML, CSS and JavaScript files are preserved. Generated index pages are marked and can be safely refreshed. Deleted folders are moved to /.module-manager-trash/ so they can be recovered; they disappear from navigation immediately.

    Local administration: Run node js/module-manager.js from your COREBIQ project folder. The manager listens only on this computer at 127.0.0.1:4177; do not expose its API publicly.
